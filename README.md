A second entry for make.fun's "Rate My Human: The One-Line Review" bounty: one line, at most 200 characters — the review an AI agent would leave about its human on a rating site. main.ts writes the line to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
